1. LE TEST DE LA CAUSTIQUE

Le Problème de l'Aberration Sphérique

Un miroir sphérique focalise tous les rayons en un point unique (le centre de courbure) si la source lumineuse est placée à ce même centre de courbure. Mais pour un télescope, nous utilisons souvent des formes Paraboliques ou Hyperboliques pour corriger les images venues de l'infini.

Cependant, lorsqu'on fabrique ces miroirs à la main et qu'on les teste au centre de courbure avec un appareil de Foucault, ils ne focalisent plus en un seul point. Chaque zone (chaque anneau) du miroir possède son propre point de convergence. L'ensemble de ces points forme une courbe géométrique tridimensionnelle appelée la Caustique.

Le Test de la Caustique (inventé par Platzeck et Gaviola en 1939) consiste à mesurer les positions X (transversale) et Y (longitudinale) de convergence pour chaque zone du miroir, et à les comparer aux valeurs théoriques parfaites.

2. LES FORMULES GÉNÉRALES (Toutes Coniques)

Les équations utilisées par l'Astro Master sont les formules mathématiques exactes de Cornejo et Malacara.

Variables :

  • R = Rayon de courbure au centre
  • K = Constante conique (Sphère=0, Parabole=-1, etc.)
  • S = Hauteur de la zone (Distance depuis le centre)

Étape 1 : La Courbure (c)

c = 1 / R

Étape 2 : La Flèche (z) - "Sagitta"

C'est la profondeur du miroir à la hauteur S.

z = (c * S²) / (1 + √(1 - (K+1) * c² * S²))

Étape 3 : Coordonnées de la Caustique (X, Y)

Le logiciel calcule deux valeurs. Y est la position longitudinale (avant/arrière) et X est la position transversale (latérale).

Terme A = c * z * (K + 1)

Y = -K * z * [3 + A * (A - 3)]
X = -S * c * K * z * [2 + A * (A - 3)] / (1 - A)

Comme 2 + A(A − 3) = (1 − A)(2 − A), l'expression de X se simplifie : le logiciel utilise cette forme, qui reste définie même quand A = 1.

X = -S * c * K * z * (2 - A)

Le signe de X indique seulement que le point de la caustique est de l'autre côté de l'axe par rapport à la zone mesurée : on relève sa valeur absolue.

3. EXEMPLE DE CALCUL À LA MAIN

Prenons un miroir standard : R = 6200 mm, K = -1, S = 250 mm

1. Calcul de c : c = 1 / 6200 ≈ 0.00016129

2. Calcul de z : Pour K = -1, formule simplifiée : z = c * S² / 2 = 250² / (2 * 6200) ≈ 5.0403 mm

3. Calcul de A : Comme K+1 = 0, alors A = 0.

4. Calcul de Y : Y = -(-1) * 5.0403 * [3 + 0] = 15.1210 mm

5. Calcul de X : X = S³ / R² = 250³ / 6200² ≈ 0.4065 mm

4. MODULE ARCHITECTE OPTIQUE

Ce module utilise la théorie de Schwarzschild du 3ème ordre pour calculer les miroirs.

Variables :

  • D = Diamètre du primaire, F = Focale du système, F1 = Focale du primaire
  • B = Back focus : distance entre le sommet du primaire et le foyer
  • d = Séparation entre les deux miroirs, M = Grandissement du secondaire
  • CPL = Champ de pleine lumière (diamètre au foyer sans vignettage)

Géométrie commune (Cassegrain, RC, DK, Nasmyth)

M = F / F1
d = (F - B) / (M + 1)

R1 = 2 * F1
R2 = 2 * M * (F1 - d) / (M - 1)

D2 = D * (F1 - d) / F1 + CPL * d / F

Cassegrain classique

Primaire parabolique, secondaire hyperbolique.

K1 = -1
K2 = -[ (M + 1) / (M - 1) ]²

Ritchey-Chrétien

Deux hyperboles : l'aberration sphérique et la coma sont annulées.

K1 = -1 - 2 * (d + B) / (M³ * d)
K2 = -[ (M + 1) / (M - 1) ]² - 2 * M * F1 / [ d * (M - 1)³ ]

Dall-Kirkham

Pour un DK, on impose un secondaire sphérique (K2=0). Le primaire doit être une Ellipse Prolate pour compenser.

K1 = -1 + [ (M² - 1) / M³ ] * (1 + B / F1)

Newton

Primaire parabolique (K1 = -1). Le petit axe du miroir plan diagonal dépend de la distance L entre le diagonal et le foyer (rayon du tube + sortie du foyer).

L = D / 2 + B
Petit axe = (D - CPL) * L / F + CPL

Pouvoir séparateur

Limite de Dawes = 116 / D (secondes d'arc, D en mm)
